ДЕЛО № 404 — ПУБЛИКАЦИЯ НА GITHUB PAGES

1. Распакуйте архив.
2. Загрузите все файлы и папку assets из архива в корень GitHub-репозитория.
3. На GitHub откройте Settings → Pages.
4. В разделе Build and deployment выберите Deploy from a branch, ветку main и папку /(root), затем Save.
5. Дождитесь публикации по адресу, указанному GitHub на странице Pages.

Ссылки на разделы после публикации:
Главная: /<репозиторий>/
Вступление: /<репозиторий>/#/intro
Показания: /<репозиторий>/#/testimonies
Реестр номеров: /<репозиторий>/#/numbers

Сайт собран как статическая версия для GitHub Pages. Для переходов внутри сайта используется адресная часть после #.
